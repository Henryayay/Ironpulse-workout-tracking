# IronPulse — Offline-Ready Workout Tracker (PWA)

## Publish on GitHub Pages
1. Unzip `ironpulse_pwa.zip` and upload all files inside `ironpulse_pwa/` (`index.html`, `manifest.json`, `sw.js`, `README.md`, and `icons/`) to the root of a public GitHub repository.
2. Open **Settings -> Pages**, set Branch to `main` and folder to `/ (root)`, and click **Save**.
3. Open your live link once with internet on your phone so the service worker caches styling, icons, charts, and fonts—after that, IronPulse works even in Airplane Mode.

## Install & Backup
- **iPhone (Safari):** Share -> Add to Home Screen.
- **Android (Chrome):** Menu (⋮) -> Install app.
- **Move devices:** Use **Backup JSON** and **Restore JSON** in **Progress & PRs**.
